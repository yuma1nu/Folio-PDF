# Folio PDF 0.1.2

Windows 11 x64向けのPDFビューアです。広告・アカウント登録・クラウドへの文書送信なしで利用できます。

## インストール

添付ファイルの `Folio PDF Setup 0.1.2.exe` をダウンロードして実行してください。ソースコードのZIPは利用時には不要です。Node.jsなどの開発環境も不要です。

## 主な機能

- タブと別ウィンドウでのPDF閲覧。
- サムネイル、全文検索、文字選択、25〜1600%の拡大表示。
- 図面向けの部分的な高精細描画と高DPI対応。
- ページの並べ替え・削除・回転、結合・抽出、別名保存。
- 印刷、閲覧状態の復元、ライト／ダーク／OSテーマ追従。

## この版の変更

上部の「ライブラリ ＞ ファイル名」を削除し、サイドバー開閉ボタンと保存状態をツールバーへ統合しました。前版では、サイドバー折り畳み時の幅を48pxに修正しています。

## 留意事項

- コード署名は付けていません。会社のPCではアプリ導入ポリシーに従ってください。
- 実プリンターでの検証は未実施です。印刷用ページは150dpiの画像として生成します。
- 暗号化や編集制限のあるPDFの編集、OCR、本文編集、注釈作成には対応しません。
- 既存のしおり・フォーム等はページ編集時に完全には保持されません。原本を残して保存してください。

実装・検証の詳細はREADMEおよび `docs/validation.md` を参照してください。
